Architectural Philosophy

Why Vertical Slices Beat Traditional Layered Systems

✕

Traditional Layered / Clean Architecture

  • • Artificial Horizontal Division: Adding one simple feature requires modifying Controllers, UseCases, Domain Entities, Repository Interfaces, and SQL Implementations.
  • • AI Agent Merge Conflicts: When multiple AI agents or engineers touch shared generic repositories or services, merge conflicts explode.
  • • Bloated Generic Classes: "ProductService" ends up with 25 methods and 1,500 lines of entangled responsibilities.
✓

PricePulse Vertical Slice Architecture (VSA)

  • • Self-Contained Use Cases: Slices encapsulate DTO (Zod), Endpoint, Handler (direct Drizzle SQL), and Module in one single folder.
  • • AI-First & Worktree Isolation: AI agents develop slices in parallel inside isolated Git Worktrees touching only their folder, with zero risk of merge collisions.
  • • Compiler-Enforced Guardrails: dependency-cruiser automatically fails CI if any slice imports code from another slice.

Production Catalog

Implemented Vertical Slices

HTTP Command

catalog/register-tracked-url

Validates URL with recursive Anti-SSRF, normalizes UTM parameters, extracts initial price, and emits atomic Outbox event.

POST /api/catalog/products
HTTP Command

alerts/create-user-alert

Enforces database-level uniqueness per user email on active alerts. Validates target price lower than current market price.

POST /api/alerts
Internal Command

ingestion/record-price-snapshot

Persists price history. Always updates product market price. Conditionally emits PriceDroppedEventV1 to Outbox only upon real drops.

POST /api/ingestion/snapshots
BullMQ Job Worker

scraping/schedule-url-scrape

Distributed repeatable jobs running every 4h. Rate limiting (2 req/s) via Valkey. Transitions dead products (404) to INACTIVE.

Queue: scraping-queue
NATS Consumer

notifications/notify-price-drop

Durable pull consumer with 60s AckWait. Enforces 24h notification fatigue cooldown and dispatches HTML emails via Mailpit.

Subject: pricepulse.v1.events.price.dropped

Quickstart in 3 Minutes

1. Spin up Docker Infrastructure
pnpm docker:up
# Starts Postgres 16, Valkey 8, NATS 2.10 (-js), Mailpit, and Jaeger
2. Apply Drizzle Migrations
pnpm db:migrate
3. Run Comprehensive Test Suites
pnpm test               # Fast unit tests
pnpm test:integration   # Real container integration tests (21 tests)
pnpm depcruise          # Architecture governance check
4. Start API Server (Port 3333)
pnpm start:dev
